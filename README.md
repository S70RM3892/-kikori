# ドパドパ木こり 🪓

斧をドラッグして3Dの木をスパッと斬りまくる、ドーパミン全開の木こり × インクリメンタル（放置）ゲーム。
転生すると**菌斬り次元**が開き、今度は**刀**でただよう菌（Germ）を斬りまくれる。
ビルド不要の素の HTML / CSS / JavaScript。3D は Three.js（r128）、効果音は WebAudio でその場で合成していて、画像・音声ファイルは使っていない。

## 遊び方

- `index.html` をブラウザで開くだけ（ダブルクリックで動く）。Three.js は CDN から読み、つながらないときは同梱の `vendor/three.min.js` を使う。
- **GitHub Pages で遊ぶ**: リポジトリの Settings → Pages → Build and deployment の Source を「Deploy from a branch」にし、Branch に `ccr-206907eb-cl4092`（またはこれをマージしたブランチ）と `/ (root)` を選んで Save。数分で `https://s70rm3892.github.io/-kikori/` で遊べる。ビルドは不要（`.nojekyll` 付き）。
- **端末ごとのセーブ**: 進行はその端末のそのブラウザの中（localStorage）に自動で保存されるので、スマホ・PC・家族の端末などで別々のデータで遊べる。データを移すときは 設定 → 書き出し / 読み込み。スマホはホーム画面に追加するとアプリのように全画面で遊べる（`manifest.webmanifest`）。
- 画面いっぱいの3Dの森で、**斧をドラッグして幹を左右に横切るように振る**と1撃入る。速く振るほど強く、幹の金色の帯（切り込み）を通すと **JUST**。
- 強化は画面の縁のウィジェットから。左は【木こり・強化・ガチャ】、右は【任務・実績・転生】。押すと横から引き出しが出る。
- 下のドックには「いま一番お得な木こり」「次の斬撃強化」「その他の強化」「受け取れるもの」が並ぶ。タップで即購入、長押しで連続購入。
- タップやスペースキーでも軽く振れるが、威力はドラッグの半分以下。
- 右上の **▶▶ ×1** ボタンで倍速モード（×1 → ×2 → ×3）。×3 はステージ30で解放。
- **転生を1回すると、右上に 🧫 ボタンが出る**。押すと菌斬り次元へ移動し、刀で菌を斬れる（もう一度押すと森へ帰る）。
- 進行は自動でブラウザに保存される（設定 → 書き出し / 読み込み でバックアップ可）。

## メインの気持ちよさ: 3Dの斬撃

斧が幹に入った瞬間に、ヒットストップ（斧が幹に食い込んで一瞬止まる）、カメラのズームと揺れ、幹の白い閃き、振った方向へ飛ぶ3Dの木片と葉、火花、閃光、ダメージ数字が重なる。

## 菌斬り次元（転生で開く）

転生を1回すると、もう一つの世界「菌斬り次元」へ行けるようになる（右上の 🧫）。顕微鏡をのぞいたような液体の世界に、顔のある菌がただよっている。

### v2: 斬る気持ちよさを森以上に

- **居合の「間」**: 斬った菌は一瞬止まって切り筋が光り、一振りで斬った菌はまとめて「ズバババッ!!」と真っ二つに割れる。
- **群れ**: 一振りでまとめて斬れる隊列が数秒ごとに来る（下から放り上がる横一列・縦一列・弧・回る輪・蛇・V字・破裂）。払えば DOUBLE → TRIPLE → … PENTA KILL!!! と掛け声が上がり、一体ごとに音階が上がる。全滅させると全滅ボーナス。
- **斬撃ランク E〜SSS**: 勢いと斬り方の多彩さ（違う株を続けて斬る）で上がる。上がるほどDNA・刀ガチャが伸び、背景・刀の軌跡の色・画面の縁の光・BGMの楽器が変わる。SSSは虹色。
- **無双モード**: 斬るほど無双ゲージがたまり、満タンで7秒間ダメージ×4・DNA×2・群れが押し寄せる。画面の縁が虹色に脈打ち、刀が大きく光る。
- **誘爆**: 💣爆裂菌や誘爆で菌が爆発して周りを巻きこみ、「誘爆 ×5! ×6!」と連鎖する。連鎖ボーナスつき。
- **秘技**: ⚡雷刃（近くの菌へ雷が走る）・🔥炎刃（燃え続ける）・❄️氷刃（凍らせて次の一太刀で「砕!!」×2.5）。
- **当たり**: 🎰スロット菌（3つのリールが回って、777でDNA×50）・📦宝箱菌・🍀ラッキー細胞（画面を横切る金色の細胞。斬ると大当たり）。
- **ボス**: 体力が減ると PHASE 2・3 で暴走し、周りを回る光る**弱点**を斬ると×8。とどめはスローモーションの「一刀両断!!」と画面を両断する一筋。
- **菌図鑑**: 初めて斬った株は「NEW!」で図鑑に登録（10種ごとにDNA +4%）。刀が近づくと菌が震えて冷や汗をかく。

- **刀をドラッグして菌を斬る**。刀は指に追従し、振った線が菌の円を通ると1太刀。速く振るほど強く、**菌の中心（芯）**を通すと ×2。
- **一閃**: 前の1体から0.5秒以内に斬り続けると、同じ一振りとして数える。2体目以降はダメージとDNAが上がり、手を止めると「チン」と刀を納めて「一閃 ×N」（二枚おろし・三段斬り…百花繚乱・無双）。
- **斬られた菌は斬った向きで2つに割れ**、断面（中身の色）を見せながら飛び散る（3Dのクリッピング平面）。しずくが飛び、DNA がカウンターへ吸い込まれる。
- **連斬**（コンボ）が続くとダメージ・刀ガチャの回転と幸運が上がり、十人斬り・百人斬り・千人斬りで画面が沸く。BGM も連斬に合わせて楽器が増える（この次元では半音で揺れる妖しい音階）。
- **ウェーブ**: 25体でウェーブが進み、10ウェーブごとに**巨大病原体**（王冠つきのボス。30秒以内に倒す。手下を呼ぶ）。倒すと 🧪**変異因子**とジェム。
- **特殊な菌**: 黄金菌（DNA ×25、7秒で逃げる）・虹色菌（斬ると大発生）・巨大・装甲（遅い振りは弾かれる。速く振るか芯を通す）・分裂（斬ると2体に）・幽霊（ときどき透けて斬れない）。アメーバは斬ると分裂し、カビの胞子は小さな胞子をまく。
- **☣️ 大発生**: ときどき菌が一気に湧く（数が2.4倍・体力が1/3・DNA ×3・ダメージ ×2・刀ガチャ ×2）。一閃の大チャンス。
- **免疫細胞**（放置）: 好中球・マクロファージ・樹状細胞・NK細胞・キラーT細胞・ヘルパーT細胞・B細胞・記憶細胞（ここまで実在の細胞。説明は医学の資料に沿わせた）と、空想の抗体ミサイル・ナノボット隊など全14種。画面の端から飛んできて菌を食べる。森にいる間も、離れている間もDNAを稼ぐ。
- **研ぎ**（DNAで買う）: 切れ味・抜刀術・一閃・芯斬り・連斬・会心・残心（遅れてもう一太刀）・斬撃波（当たり判定が広がる）・DNA解析・培養（同時に出る菌が増える）・黄金菌センサー・大発生・免疫強化・病原体特効・刀ガチャの回転と幸運。
- **刀ガチャ**: この次元にいる間ずっと自動で回る（斧ガチャと同じ 1/N の判定）。木刀・竹光から、氷刃「霜月」、抗生剣ペニシリン、量子刀「重ね合わせ」、天叢雲、星斬り、神殺し、Ω・終刀まで48本。SSR以上の刀は**奥義**つきで、ゲージが満ちるとカットインのあと画面の菌を一斉に斬る（十字・格子・星形・扇・渦など刀ごとの斬撃の形）。
- **変異**（🧪で買う、転生してもなくならない）: 光合成ブースト（森の木こりDPS）・斧の突然変異（森の斬撃）・木材の発酵・ガチャ細胞分裂（両方のガチャの回転）・幸運遺伝子・精霊との共生・冬眠遺伝子（離れている間の効率）・完全変異（両方の全ダメージ）など16種。**菌斬り次元で強くなるほど森も強くなる**。
- **2つの世界のつながり**: 森の斧を1種類集めるごとに刀のダメージ +1%、刀を1種類集めるごとに森の全ダメージ +1%。精霊（転生）と実績は両方に効く。菌斬り次元にいる間も森の木こりは働き、斧ガチャは静かに回って、森に戻ったときにまとめて知らせる。

- **待っている間**: SSR 以上の斧は幹の横に浮かんで、斧ごとの動き（呼吸・上下・回転・震え・周回…）で待っている
- **斬るたびの演出**: 普通の形の SSR 以上（金の斧・竜殺し・星砕き・木喰・世界樹・黒曜石・ラグナロク・ヴォイド・クロノス・森羅万象・∞）にも専用の斬撃演出

ランクが上がるたびに大きな文字が画面の真ん中に叩きつけられ、画面いっぱいの衝撃波が走り、端のボタンとドックが順番に跳ねる。フィーバー中は BGM が最大になる。

同じ演出の繰り返しにならないように、毎回違いが出る:

- 斬撃の形: ふつうは一閃、JUST は三日月、会心は十字。角度も毎回揺れる
- 擬音: 場面ごとに言葉が変わる（ズバッ / ドゴォッ（会心）/ キィン（JUST）/ ズババババ（フィーバー））、色もランクで変わる
- 倒し方: 回って吹っ飛ぶ / 空のかなたへ飛んで「キラーン☆」と光る（最速で斬ったとき）/ 粉々に砕ける（会心・複数本）。ランクが高いほど派手な倒れ方が増える
- 大きな一撃では画面ごと傾き、向きは毎回変わる

BGM は設定で OFF にできる。夜ふかしガード中は鳴らさない。

## 倍速モード

右上のボタンで ×1 → ×2 → ×3（×3 はステージ30で解放）。木こりの働き、木の生え変わり、倒れる速さ、リスの出現、ガチャ演出が速くなる。フィーバー・ゴールデンタイム・ボスの制限時間・コンボ受付は実時間のままなので、人の操作は急かされない。夜ふかしガード中は等速に戻る。

## ハマりすぎ防止

- **勉強ブースト（📚）**: 25 / 50 / 90 分ゲームをロック。完走するとその時間ぶんの木材 ×2・ジェム・ガチャチケット。途中でやめるとボーナスなし。タブを閉じても時間はカウントされる。
- **夜ふかしガード**: 22時以降は演出を抑えて画面を暖色に、倍速も止める。23時以降は「寝ろ」と言ってくる（設定で OFF 可）。
- **睡眠ボーナス**: 6時間以上離れて戻るとオフライン報酬 ×1.5。寝てる間も木こりは働く。
- 設定でフラッシュ・画面揺れ・エフェクト量を調整できる。OS の「視差効果を減らす」（アニメーションを減らす）設定にも従う。重い端末では3Dの描画解像度を自動で下げる。

## バランス調整

`tools/sim.js` は `js/` のロジックをそのまま読み込み、貪欲に買い物をするボットを走らせて進行速度を出す。斬撃は「人間が普通に頑張ったときの速さランクの分布と JUST 率」でモデル化している。

```sh
node tools/sim.js 180 2 [seed]   # 180分、毎秒2回幹を斬り続けるボット
SIM_CFG='{"HP_G1":1.7}' node tools/sim.js 120 2   # data.js の CFG を上書きして試す
SIM_SPEED=2 node tools/sim.js 90 2                 # 倍速モードで試す
```

現在の数値（毎秒2回斬り続けるボット）: ステージ100 ≒ 5分、150 ≒ 8分、200 ≒ 14分、最初の転生 ≒ 37分（ステージ240。木こり25種・斧834本のぶん、前の版より奥まで進めるようになった）。人間はボットより買い物も斬るのも遅いので、体感はこの1.5〜3倍。次の木がすぐ生えるぶん、1ステージは15本にしている。オートガチャは斧1本あたりの力を小さくし、回転と幸運の伸びをガチャLv（回した回数）に結びつけて、木材のインフレで一気に強くならないようにしている。

菌斬り次元は `tools/germsim.js` で同じように確かめる（1回転生した直後の状態から、毎秒1.2回刀を振って1〜6体まとめて斬るボット）。

```sh
node tools/germsim.js 90 1.2 5   # 90分、毎秒1.2回振る、精霊5体
SIM_GCFG='{"HP_G":1.32}' node tools/germsim.js 60 1.2 30   # germdata.js の CFG を上書き
```

現在の数値（v2、精霊5体）: ウェーブ100 ≒ 9分、135 ≒ 15分、150 ≒ 30分、160 ≒ 45分。そこから先はボス病原体が壁になり、森での転生・変異・刀の収集で突破していく。1ウェーブは45体（群れで斬る数が増えたぶん多め）。菌の体力はウェーブごとに ×1.33、DNA は ×1.18（体力の伸びを上回らないようにして、免疫細胞とDNA解析が勝手に暴走しないようにしている）。スロットやラッキー細胞の当たりは「最近の稼ぎ」ではなくウェーブで決まる量にしている（稼ぎに比例させると当たりが次の当たりを大きくして止まらなくなるため）。

コストは「指数で増え、生産は線形〜多項式で増える」というインクリメンタルゲームの定石に沿って、木こりは1人ごとに ×1.15、木の HP はステージごとに ×1.65（101以降 ×1.25）。
