# ドパドパ木こり 🪓

斧をドラッグして木をスパッと斬りまくる、ドーパミン全開の木こり × インクリメンタル（放置）ゲーム。
ビルド不要の素の HTML / CSS / JavaScript で、画像・音声ファイルも使っていない（木も斧も Canvas で描画、効果音は WebAudio でその場で合成）。

## 遊び方

- `index.html` をブラウザで開くだけ（ダブルクリックで動く）。GitHub Pages に置いてもそのまま動く。
- **斧をドラッグして、幹を左右に横切るように振る**と1撃入る。速く振るほど強く、切り込み（金色の的）の高さを通すと **JUST**。
- タップやスペースキーでも軽く振れるが、威力はドラッグの半分以下。
- 木材で【木こり】を雇うと自動で伐ってくれる。【強化】でタップや会心を伸ばす。
- 進行は自動でブラウザに保存される（設定 → 書き出し / 読み込み でバックアップ可）。

## メインの気持ちよさ: 斬撃

斧が幹に入った瞬間に、ヒットストップ（斧が一瞬食い込んで止まる）、カメラのズーム、振った方向へ飛ぶ木片と火花、斬撃の跡、閃光、ダメージ数字が重なる。

| 要素 | 中身 |
| --- | --- |
| 速さランク | ソフト → NICE → GOOD! → GREAT!! → EXCELLENT!!! → MAX SPEED!!!!（時速表示つき） |
| JUST | 切り込みの高さで斬ると倍率アップ＋金属音。連続で決めると JUST ×2, ×3… と音程と倍率が上がる |
| 斬撃強化 | 強化するほど数字と演出の両方が増える（下表） |

| 強化 | 効果 | 演出解放 |
| --- | --- | --- |
| 剛腕スイング | 速さボーナス +15%/Lv | Lv1 光る軌跡 → Lv10 二重 → Lv25 虹色 → Lv40 炎の軌跡 |
| 見切り | JUSTの幅・倍率・連続上限 | Lv1 衝撃波 → Lv10 黄金の波紋 → Lv25 スローモーション |
| 残像斬り | 残像が追撃 | Lv1 残像1体 → Lv15 2体 → Lv30 3体 |
| 雷神の加護 | 斬るたびに落雷 | Lv1 落雷 → Lv15 二連雷 → Lv30 三連神雷 |
| 爆裂斬 | コンボ中、一定回数ごとに爆発 | Lv1 爆裂 → Lv10 大爆裂 → Lv20 超新星 |
| 会心の一撃 | 会心倍率 | Lv10 会心の衝撃波 → Lv20 会心で時が止まる |

演出が解放されるたびに「演出解放！」のバナーが出る。強化レベルの合計で、ヒットストップ・揺れ・破片の量も増える。

## ハマりすぎ防止

- **勉強ブースト（📚）**: 25 / 50 / 90 分ゲームをロック。完走するとその時間ぶんの木材 ×2・ジェム・ガチャチケット。途中でやめるとボーナスなし。タブを閉じても時間はカウントされる。
- **夜ふかしガード**: 22時以降は演出を抑えて画面を暖色に、23時以降は「寝ろ」と言ってくる（設定で OFF 可）。
- **睡眠ボーナス**: 6時間以上離れて戻るとオフライン報酬 ×1.5。寝てる間も木こりは働く。
- 設定でフラッシュ・画面揺れ・エフェクト量を調整できる。OS の「視差効果を減らす」（アニメーションを減らす）設定にも従う。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     見た目
js/util.js        数値表記（漢数字単位）・乱数・イージング
js/data.js        バランス数値とデータ（木こり・強化・斧・バイオーム・実績…）
js/game.js        ゲームロジック（DOM 非依存。イベントで演出側に通知）
js/audio.js       WebAudio 効果音
js/fx.js          Canvas 描画（木・斧・軌跡・斬撃の演出・背景・パーティクル・ダメージ数字）
js/input.js       斧のドラッグ操作（幹を横切った位置・速さ・JUST判定）
js/ui.js          HUD・タブ・モーダル・トースト
js/main.js        起動とメインループ・自動セーブ・オフライン計算
tools/sim.js      バランスシミュレータ
```

## バランス調整

`tools/sim.js` は `js/` のロジックをそのまま読み込み、貪欲に買い物をするボットを走らせて進行速度を出す。斬撃は「人間が普通に頑張ったときの速さランクの分布と JUST 率」でモデル化している。

```sh
node tools/sim.js 180 2 [seed]   # 180分、毎秒2回幹を斬り続けるボット
SIM_CFG='{"HP_G1":1.7}' node tools/sim.js 120 2   # data.js の CFG を上書きして試す
```

現在の数値（毎秒2回斬り続けるボット、乱数シード5通り）: ステージ50 ≒ 8〜13分、80 ≒ 11〜19分、最初の転生 ≒ 30〜60分。人間はボットより買い物も斬るのも遅いので、体感はこの1.5〜3倍。

コストは「指数で増え、生産は線形〜多項式で増える」というインクリメンタルゲームの定石に沿って、木こりは1人ごとに ×1.15、木の HP はステージごとに ×1.65（101以降 ×1.25）。
