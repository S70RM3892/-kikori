# ドパドパ木こり 🪓

斧をドラッグして3Dの木をスパッと斬りまくる、ドーパミン全開の木こり × インクリメンタル（放置）ゲーム。
ビルド不要の素の HTML / CSS / JavaScript。3D は Three.js（r128）、効果音は WebAudio でその場で合成していて、画像・音声ファイルは使っていない。

## 遊び方

- `index.html` をブラウザで開くだけ（ダブルクリックで動く）。GitHub Pages に置いてもそのまま動く。
  Three.js は CDN から読み、つながらないときは同梱の `vendor/three.min.js` を使う。
- 画面いっぱいの3Dの森で、**斧をドラッグして幹を左右に横切るように振る**と1撃入る。速く振るほど強く、幹の金色の帯（切り込み）を通すと **JUST**。
- 強化は画面の縁のウィジェットから。左は【木こり・強化・ガチャ】、右は【任務・実績・転生】。押すと横から引き出しが出る。
- 下のドックには「いま一番お得な木こり」「次の斬撃強化」「その他の強化」「受け取れるもの」が並ぶ。タップで即購入、長押しで連続購入。
- タップやスペースキーでも軽く振れるが、威力はドラッグの半分以下。
- 右上の **▶▶ ×1** ボタンで倍速モード（×1 → ×2 → ×3）。×3 はステージ30で解放。
- 進行は自動でブラウザに保存される（設定 → 書き出し / 読み込み でバックアップ可）。

## メインの気持ちよさ: 3Dの斬撃

斧が幹に入った瞬間に、ヒットストップ（斧が幹に食い込んで一瞬止まる）、カメラのズームと揺れ、幹の白い閃き、振った方向へ飛ぶ3Dの木片と葉、火花、閃光、ダメージ数字が重なる。
切り込みは斬るたびに3Dで深くえぐれていき、倒すと上半分が斬った向きへ回りながら吹っ飛び、切り株の年輪が一瞬見える。次の木は約0.1〜0.2秒でボヨンと生えるので、手を止めずにザクザク斬り続けられる。ボスとレア木だけは、とどめでスローモーションになって倒れ、着地で地響きと土煙が上がる。

| 要素 | 中身 |
| --- | --- |
| 速さランク | ソフト → NICE → GOOD! → GREAT!! → EXCELLENT!!! → MAX SPEED!!!!（時速表示つき） |
| JUST | 金色の帯の高さで斬ると倍率アップ＋金属音。連続で決めると JUST ×2, ×3… と音程と倍率が上がる |
| 斬撃倍率メーター | コンボ × フィーバー × バフ × JUST連続 の今の倍率を右上に表示。斬り続けるほど伸びる |
| 斬撃強化 | 強化するほど数字と演出の両方が増える（下表） |

| 強化 | 効果 | 演出解放 |
| --- | --- | --- |
| 剛腕スイング | 速さボーナス +15%/Lv | Lv1 光る軌跡 → Lv10 二重 → Lv25 虹色 → Lv40 炎の軌跡 |
| 見切り | JUSTの幅・倍率・連続上限 | Lv1 衝撃波 → Lv10 黄金の波紋 → Lv25 スローモーション |

| 爆裂斬 | コンボ中、一定回数ごとに3Dの爆発 | Lv1 爆裂 → Lv10 大爆裂 → Lv20 超新星 |
| 会心の一撃 | 会心倍率 | Lv10 会心の衝撃波 → Lv20 会心で時が止まる |

## オートガチャ（ずっと自動で回る）

ガチャは画面下の帯でずっと回っている。最初は毎秒2回転。引いた結果はレアの色のチップになって帯を流れ、レアが出ると小さなカードが飛び出し、初めての LR 以上や MYTH 以上は画面いっぱいの演出になる。離れている間も回り、戻ると「その間に何万回まわったか」とレアの内訳が出る。

| レア | 確率 | | レア | 確率 |
| --- | --- | --- | --- | --- |
| N | 1/2 | | LR | 1/2,000 |
| R | 1/4 | | EX | 1/15,000 |
| SR | 1/10 | | MYTH | 1/100,000 |
| SSR | 1/40 | | GOD | 1/1,000,000 |
| UR | 1/250 | | Ω | 1/10,000,000 |

- レアから順に「1/N × 幸運」で判定する。同じ斧を引くほど枚数が増え、枚数が2倍になるごとに Lv が上がる（上限なし）
- **回転が速くなる**: ガチャLv・強化「高速回転」・フィーバー（×2）・スタイルランク（最大×1.7）・倍速モード・ジェムショップのオイル（×2・×5）
- **幸運が上がる**: ガチャLv・強化「ガチャの幸運」・スタイルランク・ゴールデンタイム（×2）・お守り（×2・×10）・一部の斧とセット
- **ガチャLv**: 回した回数で上がり、上がるたびに回転・幸運・ジェム、5Lvごとにチケット
- **プレミアムガチャ**: ジェムかチケットで引くと幸運×5、10連は SR 以上確定、天井あり、日替わりピックアップ
- **斧のセット**（11種）: そろえると永続ボーナス（はじまりの斧・金銀銅・四元素・宝石箱・おかしな斧・天空・宇宙・武人・神々・神話・神の領域）
- **ジェムショップ**: 幸運のお守り・高速回転オイル・奇跡のお守り・超高速モーター・木こりのおにぎり・剛力ドリンク・フィーバー薬・黄金の果実

## 画面全体が語りかける: スタイルランク

左上の **STYLE** は斬り方の勢い。速く・JUSTで・会心で・何本もまとめて斬るほど上がり、手を止めると下がる。直前と違う斬り方（速さ・JUST・会心の組み合わせ）を混ぜると少し多めに上がる。

| ランク | 言葉 | 報酬 | 画面の変化 |
| --- | --- | --- | --- |
| D | ザクッ | ×1.03 | BGM のキックが鳴り始める |
| C | ノッてきた! | ×1.06 | 画面の縁が緑に光る・ハイハット |
| B | アツい!! | ×1.1 | 空がランクの色に染まり始める・ベース。ここから BGM の拍で画面が脈打つ |
| A | 止まらない!! | ×1.15 | 画面の下から火の粉が昇る・クラップ |
| S | 神斬り!!! | ×1.25 | 端のボタンがランクの色に光る・アルペジオ。ランクアップで集中線と画面の傾き |
| SS | 天下無双!!!! | ×1.35 | 16分のハイハットが加わる |
| SSS | 森羅万象!!!!! | ×1.5 | 空・縁・火の粉・ボタンが虹色に回り、BGM が全部の楽器で鳴る |

ランクが上がるたびに大きな文字が画面の真ん中に叩きつけられ、画面いっぱいの衝撃波が走り、端のボタンとドックが順番に跳ねる。フィーバー中は BGM が最大になる。

同じ演出の繰り返しにならないように、毎回違いが出る:

- 斬撃の形: ふつうは一閃、JUST は三日月、会心は十字。角度も毎回揺れる
- 擬音: 場面ごとに言葉が変わる（ズバッ / ドゴォッ（会心）/ キィン（JUST）/ ズババババ（フィーバー））、色もランクで変わる
- 倒し方: 回って吹っ飛ぶ / 空のかなたへ飛んで「キラーン☆」と光る（最速で斬ったとき）/ 粉々に砕ける（会心・複数本）。ランクが高いほど派手な倒れ方が増える
- 大きな一撃では画面ごと傾き、向きは毎回変わる

BGM は設定で OFF にできる。夜ふかしガード中は鳴らさない。

## 倍速モード

右上のボタンで ×1 → ×2 → ×3（×3 はステージ30で解放）。木こりの働き、木の生え変わり、倒れる速さ、リスの出現、ガチャ演出が速くなる。フィーバー・ゴールデンタイム・ボスの制限時間・コンボ受付は実時間のままなので、人の操作は急かされない。夜ふかしガード中は等速に戻る。

## ハマりすぎ防止

- **勉強ブースト（📚）**: 25 / 50 / 90 分ゲームをロック。完走するとその時間ぶんの木材 ×2・ジェム・ガチャチケット。途中でやめるとボーナスなし。タブを閉じても時間はカウントされる。
- **夜ふかしガード**: 22時以降は演出を抑えて画面を暖色に、倍速も止める。23時以降は「寝ろ」と言ってくる（設定で OFF 可）。
- **睡眠ボーナス**: 6時間以上離れて戻るとオフライン報酬 ×1.5。寝てる間も木こりは働く。
- 設定でフラッシュ・画面揺れ・エフェクト量を調整できる。OS の「視差効果を減らす」（アニメーションを減らす）設定にも従う。重い端末では3Dの描画解像度を自動で下げる。

## バランス調整

`tools/sim.js` は `js/` のロジックをそのまま読み込み、貪欲に買い物をするボットを走らせて進行速度を出す。斬撃は「人間が普通に頑張ったときの速さランクの分布と JUST 率」でモデル化している。

```sh
node tools/sim.js 180 2 [seed]   # 180分、毎秒2回幹を斬り続けるボット
SIM_CFG='{"HP_G1":1.7}' node tools/sim.js 120 2   # data.js の CFG を上書きして試す
SIM_SPEED=2 node tools/sim.js 90 2                 # 倍速モードで試す
```

現在の数値（毎秒2回斬り続けるボット、乱数シード3通り）: ステージ100 ≒ 5〜7分、150 ≒ 9〜13分、最初の転生 ≒ 50〜96分（ステージ180〜200）。人間はボットより買い物も斬るのも遅いので、体感はこの1.5〜3倍。次の木がすぐ生えるぶん、1ステージは15本にしている。オートガチャは斧1本あたりの力を小さくし、回転と幸運の伸びをガチャLv（回した回数）に結びつけて、木材のインフレで一気に強くならないようにしている。

コストは「指数で増え、生産は線形〜多項式で増える」というインクリメンタルゲームの定石に沿って、木こりは1人ごとに ×1.15、木の HP はステージごとに ×1.65（101以降 ×1.25）。
